# Smart Expense Tracking and Budget Analysis System

An intelligent, full-stack financial monitoring system built with **Next.js 14**, **TypeScript**, **Prisma**, **SQLite**, and **TailwindCSS**. It provides AI-powered expense categorization, predictive budget tracking, real-time anomaly alerts, and interactive financial charts.

---

## 🎯 Key Features

- 📊 **Interactive Dashboard**: Real-time spending overview, balance tracking, and monthly comparisons.
- 💸 **Expense Management**: Add, filter, search, update, and delete expenses effortlessly.
- 🎯 **Goal-Based Savings**: Track financial goals with interactive progress indicators and target dates.
- 🛡️ **Anomaly & Fraud Detection**: Automated alerts flagging unusual transaction spikes or duplicate charges.
- 📈 **Visual Analytics**: Dynamic Recharts visualizations for monthly trends and category distributions.
- 💾 **SQLite & Prisma Database**: Lightweight, zero-config local database setup.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Database**: [SQLite](https://sqlite.org/) via [Prisma ORM](https://www.prisma.io/)
- **Styling**: [TailwindCSS](https://tailwindcss.com/) & Glassmorphism UI
- **Icons & Visuals**: Lucide React & Recharts

---
